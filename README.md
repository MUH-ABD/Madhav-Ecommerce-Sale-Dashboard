Madhav Ecommerce Sales Dashboard

An interactive Power BI dashboard created to track, analyze, and visualize online sales data. This project helps understand sales performance, customer behavior, product categories, payment methods, and monthly profit trends using dynamic and customized visualizations.

Project Overview

This dashboard was developed using Power BI to perform data analysis on ecommerce sales data. The project focuses on creating meaningful insights through interactive reports and customized visualizations.

Features
Interactive sales dashboard for ecommerce data analysis
Dynamic filtering using slicers and filters
Drill-down analysis with customized parameters
Monthly profit and sales trend analysis
Category and sub-category performance tracking
Payment mode analysis
User-driven data exploration
Dashboard Visualizations

Slicers
